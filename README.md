### 🧠 소프트 스킬 — AI 시대에 실제로 값이 매겨지는 것들

- **문제 정의** — 모호한 요구사항을 인터뷰로 좁혀 실행 가능한 스펙으로 바꿉니다. AI는 잘못된 문제도 아주 빠르게 풀어냅니다.
- **컨텍스트 설계** — 에이전트가 옳은 판단을 하도록 규칙·경계·예시를 문서로 남깁니다. 프롬프트보다 오래 갑니다.
- **검증과 회의(懷疑)** — 그럴듯한 코드와 맞는 코드를 구분합니다. 테스트와 리뷰가 유일한 방어선입니다.
- **작게 쪼개기** — 큰 기능을 세로로 얇게 저며 배포 가능한 단위로 만듭니다. 사람에게도 에이전트에게도 같은 원칙입니다.
- **기록** — 왜 그렇게 결정했는지 남깁니다. ADR 없는 코드베이스는 3개월 뒤의 나에게 레거시입니다.
